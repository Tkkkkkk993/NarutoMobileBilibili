# 暴怒带土初版

本版完成待机、移动和四段普攻动作衔接，沿用现有实体基类与图形化事件表。

- `entity.tscn`：idle、run、a1～a4、scroll、summon 共 8 个动画；帧按素材文件名顺序排列。idle 为 8 FPS，其余为 12 FPS，单帧时长初值为 1。
- `main.tres`：横向移动速度 350，纵向 175；实际移动沿用基类的奔跑倍率与惯性。
- `visual_script.json`：采用“普攻 → a1/a2/a3/a4”分组，模仿神秘面具男的普攻事件表。各段使用“动画帧”，第 0 帧根据移动输入转向；衔接按“帧数范围 → 是否按下普攻 → 播放下一段”分层编写。a1、a2 的窗口为第 5～7 帧，a3 为第 11～14 帧，帧号从 0 开始。按键在动画帧推进时检查，按住可连续衔接；未接续则播完回待机，a4 播完回待机。结束事件保留当前动画检查，避免被打断时覆盖新动作。
- `entity_frame_data.json`、`attack_boxes.json`：锚点、受击框与攻击框由用户继续编辑。各段“当攻击框命中”下的“对实体攻击”动作，目标需要设为表达式 `target`（本次命中的实体），不能留空，也不是字符串字面量 `"target"`。目前四段均按用户参数配置为平推、30000 伤害、约 0.4 秒僵直；若要击飞，需要另外配置攻击类型和 Z 速度。
- 原始图片保留完整画布；统一锚点为 (0.5, 165.5)，角色缩放为 1.2，保留 3A 素材本身的腾空偏移。
- scroll、summon 只组装动画，本次没有新增技能逻辑。入场缺少 entry 动画时沿用基类的直接待机回退。
- portraits 下三张图片从待机帧生成，仅供选人、载入和战斗头像暂用。

在实体编辑器加载 `res://assets/entities/暴怒带土/entity.tscn`，即可编辑帧数据、事件表并测试。也可从选人界面选择“暴怒带土”。
